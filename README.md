# T-Embed Lab

Мультитул-прошивка для **LILYGO T-Embed (ESP32-S3)** с меню на энкодере
и веб-установщиком «в один клик», как у Bruce.

Модули: Система · Среда (BME280) · Часы (интернет) · Секундомер ·
Сканер Wi-Fi · RGB-подсветка · Фонарик · Настройки.
Только легальные функции — без атак на чужие устройства.

---

## Вариант A. Установить готовую прошивку (просто)

После того как вы один раз настроите репозиторий (см. ниже), появится
страница-установщик. Откройте её в **Chrome или Edge на компьютере**,
подключите плату по USB-C и нажмите **«Установить прошивку»**.

Адрес страницы будет такой:

```
https://ВАШ_ЛОГИН.github.io/tembed-lab/
```

---

## Как включить веб-установщик (один раз, ~5 минут)

1. Заведите бесплатный аккаунт на https://github.com (если ещё нет).
2. Создайте новый репозиторий с именем **`tembed-lab`** (Public).
3. Загрузите в него все файлы из этой папки
   (кнопка **Add file → Upload files**, перетащите всё, включая папки
   `.github`, `TEmbedLab`, `docs`).
4. Откройте **Settings → Pages**. В разделе *Build and deployment*
   выберите **Source: GitHub Actions**.
5. Откройте вкладку **Actions**. Если предложит включить —
   нажмите **I understand… → Enable**. Сборка запустится сама
   (или запустите вручную: workflow *Сборка прошивки…* → **Run workflow**).
6. Через 3–5 минут сборка станет зелёной. Готово —
   заходите на `https://ВАШ_ЛОГИН.github.io/tembed-lab/`.

При каждом изменении кода прошивка пересоберётся, а установщик
обновится автоматически.

## Вариант B. Через Arduino IDE (если хотите править код)

1. Установите Arduino IDE 2.x и поддержку плат ESP32.
2. Библиотеки (Менеджер библиотек):
   - **GFX Library for Arduino** (moononournation) — обязательно
   - **Adafruit BME280 Library** + **Adafruit Unified Sensor** —
     только если есть датчик (иначе в `.ino` поставьте `ENABLE_BME280 0`)
3. Откройте `TEmbedLab/TEmbedLab.ino`. Настройки платы (меню Tools):
   - Board: **ESP32S3 Dev Module**
   - USB CDC On Boot: **Enabled**
   - PSRAM: **OPI PSRAM**
   - Flash Size: **16MB**
4. Впишите Wi-Fi (`WIFI_SSID`, `WIFI_PASS`) — нужно для «Часов».
5. Нажмите **Upload**.

## Управление (один энкодер)

- **Крутить** — выбор пункта / изменение значения
- **Короткое нажатие** — открыть / действие
- **Долгое нажатие (>0.6 с)** — назад в меню

---

## Если что-то не так

- **Чёрный экран** — проверьте PSRAM: **OPI PSRAM**. Прошивка сама поднимает
  питание платы (GPIO46).
- **Картинка сдвинута/перевёрнута** — в `.ino` поменяйте `rotation`
  (1 → 0/2/3) или смещения `35, 0` в конструкторе дисплея.
- **BME280 не найден** — проверьте провода SDA/SCL (встроенная шина 18/8).
- **Версия T-Embed CC1101** — часть пинов может отличаться; напишите,
  подставим распиновку CC1101.
